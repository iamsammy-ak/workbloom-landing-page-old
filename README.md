# Workbloom — website and landing page (archived frontend)

A static copy of the Workbloom public website as it looked in November 2026, before the landing page redesign. It is kept as a showcase of the frontend work.

- **Pages:** the landing page and the public pages in English: companies, Bloomers, about us, pricing, FAQs, blog and legal pages, plus the sign-in and sign-up screens.
- **Included:** layout, styles, fonts, images, the animated home background and the other animations.
- **Not included:** the backend. Accounts, BlooMIA chat, forms and payments don't work in this copy.
